# Задание 1. Текущий IT-ландшафт банка

[Карта IT-ландшафта](it-landscape.drawio) связывает подразделения с шестью бизнес-возможностями второго уровня. В каждой заполненной ячейке действие поясняет роль подразделения. Например, депозитный бэк-офис указывает ставку в АБС, после чего система запускает СМС. ИТ-отдел сопровождает шлюз, через который сообщение уходит оператору связи. [Исходная карта бизнес-возможностей](https://pictures.s3.yandex.net/resources/image_22_1732290403.png) · [Оргструктура и системы банка](../docs/bank.md)

[Схема интеграции приложений](application-integrations.drawio) содержит два листа. Фигуры сотрудников и подписи стрелок показывают, где для передачи данных требуется действие человека.

## Открытие депозита

Кредитный отдел ежедневно рассчитывает ставки в Excel и отправляет файл депозитному бэк-офису. После звонка клиента CRM кол-центра передаёт обращение в АБС. Бэк-офис может определить ставку до визита, а клиент получает СМС с предложением прийти в отделение. При визите без звонка сотрудник отделения запрашивает ставку по почте.

Для специальной ставки кредитный специалист оценивает риск клиента в своём разделе АБС и передаёт данные письмом. Менеджер депозитов переносит их в Excel, рассчитывает ставку и отвечает отделению. Такая передача сохраняет разграничение доступа между подразделениями, но клиент ждёт ответа сотрудников. Обычное ожидание составляет около 20 минут, при специальной ставке — до часа.

Даже с заранее известной ставкой клиент подтверждает открытие в отделении. Сотрудник создаёт депозит в АБС, выдаёт документы и загружает их после подписания. Для полностью цифрового открытия потребуется охватить и согласование ставки, и оформление документов. Для накопительных счетов кейс указывает общий канал открытия и участие бэк-офиса. Детальные шаги приведены для депозита.

## Открытие кредита

1. Сотрудник отделения регистрирует заявку в АБС. Раз в сутки заявки поступают через интеграцию по БД в Кредитный конвейер.
2. При рассмотрении заявки конвейер вызывает API скоринга. Скоринг использует суточные выгрузки из двух систем. АБС передаёт сведения о клиентах и платежах, а конвейер — сведения о номерах платежей по кредитным договорам. Кредитную историю скоринг запрашивает в БКИ онлайн.
3. Скоринг возвращает оценку. Менеджер кредитного отдела учитывает её вместе с параметрами заявки и принимает решение в конвейере.
4. Одобренная заявка переходит в финальный статус. Раз в сутки результат передаётся в АБС, которая проводит платёж для зачисления средств на счёт клиента. Даже при быстром ответе БКИ время до зачисления зависит от решения сотрудника и расписания обмена.
