# Коммиты проектной работы

Исходный коммит в main задаёт базу для сравнения. Изменения по пяти заданиям собираются в ветке sprint-3 для общего pull request в main.

При подготовке коммита руководствуйся запросом автора и правилами AGENTS.md. Тема кратко описывает фактически подготовленные изменения, например «Добавить описание банка и правила совместной работы». Ключ задачи нужен, только если его указал автор.

Просмотри состав и содержимое изменений в индексе, проверь текст на автоматические подписи и выполни git diff --cached --check. Публикуй изменения по запросу автора.
